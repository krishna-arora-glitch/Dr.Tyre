# Tyre Degradation Isolation & Strategy Simulation

This project is a complete end-to-end data pipeline and interactive UI that processes raw motorsport telemetry (via FastF1) to isolate true tyre degradation from confounding variables like fuel burn, track evolution, and traffic.

## Project Structure
*   `pipeline/`: Python data science backend.
*   `frontend/`: Vite + Vanilla JS telemetry dashboard.

## Known Limitations & Approximations
*   **Fuel loads are estimated:** Real F1 fuel telemetry is not public. The model assumes a starting load of 55kg for practice long-runs, 110kg for race runs, and a linear burn rate of 1.77kg/lap.
*   **Traffic is estimated:** We use a 3-lap rolling median anomaly detector to infer dirty air (lap times >1.5σ slower than the rolling median).

## How to Run

### 1. Run the Python Pipeline
The pipeline downloads the 2024 Singapore GP data, applies corrections, fits regression curves, and exports `model_output.json`.

```bash
cd pipeline
pip install -r requirements.txt
python run_pipeline.py
```
*(Note: FastF1 downloads gigabytes of data on the first run, which will be saved in `pipeline/cache/`. Ensure you have internet access).*

### 2. Run the Frontend Dashboard
The frontend consumes the JSON generated by the pipeline and renders the live simulation and charts.

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
